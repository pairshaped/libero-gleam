Define and enforce which Dict or map keys are allowed in the typed JSON codec.

Preferred direction:
- Support only primitive keys that can round-trip safely through JSON, matching the existing safety instinct from ETF work.
- Reject custom type keys, tuple keys, function-like values, or any key shape that would require lossy stringification.

Acceptance criteria:
- The generator accepts only supported key types or fails with a clear diagnostic.
- Encoders do not silently stringify unsupported keys.
- Decoders preserve key types for supported primitive keys.
- Tests cover String, Int, Bool if supported, and rejected user-type keys.
