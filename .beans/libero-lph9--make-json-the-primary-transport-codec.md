> *This was generated by AI during triage.*

Make JSON the primary Libero transport codec across generated client and server paths.

Goal:
- Generated push, RPC, SSR, page message, and client-context paths use one canonical typed JSON representation for Gleam values.
- ETF-specific safety and benchmark work can continue, but it is no longer the main product lane unless ETF stays exposed at a trust boundary.

Acceptance criteria:
- There is one documented typed JSON value contract used by every generated transport path.
- Generated encoders and decoders reject unsupported Gleam shapes with clear diagnostics instead of silently inventing per-path JSON shapes.
- Contract hash and version checks remain a hard compatibility gate.
- Snapshot or fixture coverage proves representative user types, constructor field shapes, maps, tuples or tuple rejection, BitArray, page messages, client context, push, RPC, and SSR all use the same dialect.
